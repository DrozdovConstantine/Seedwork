# Генератор SeedWork.Application: измерение масштаба

17 ноября 2026; Windows 11, .NET 11.0.0 x64, SDK 11.0.100, Roslyn 4.14.0, BenchmarkDotNet 0.15.8, Release, ShortRun, InProcessEmitToolchain, 3 прогрева и 3 измерения. Внутрипроцессный запуск выбран, поскольку стандартный запуск BenchmarkDotNet 0.15.8 не распознаёт .NET 11. Результаты ориентировочные; ошибка измерения для 100/5 велика.

Каждый сценарий имеет отдельный тип запроса и обработчик. Каждый шаг — открытый generic-тип, совместимый со всеми сценариями. Время включает создание нового GeneratorDriver и RunGenerators для заранее подготовленной CSharpCompilation, но не создание входных текстов, компиляции и ссылок, проверку результата или остальную сборку. Это повторная генерация на прогретой компиляции, а не измерение полного холодного запуска сборки или инкрементальной сборки. Размер — UTF-8 сгенерированного исходного текста, не размер DLL.

Dry-запуск инициализировал все пять вариантов; каждый вариант проверен на отсутствие ошибок генератора и компиляции сгенерированного кода. Числа сборок мусора и доверительные интервалы находятся в отчёте BenchmarkDotNet в generator-results. Лог также фиксирует отказ доступа к системной информации о процессоре; он не помешал запуску измерений.

Размер растёт вместе с числом сочетаний сценариев и совместимых шагов: генератор создаёт отдельные проверки и описания совместимости для каждого сценария. Это наблюдение по коду и размеру результата, а не профиль времени. Для решения об оптимизации нужно сравнить изменённую реализацию на тех же входах; текущие данные не выделяют отдельную стоимость обхода типов и проверки совместимости.
