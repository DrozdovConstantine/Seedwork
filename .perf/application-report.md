# SeedWork.Application: базовые измерения

17 ноября 2026; Windows 11, .NET SDK 11.0.100, .NET 11.0.0 x64, BenchmarkDotNet 0.15.8. ShortRun, InProcessEmitToolchain, 3 warmup и 3 измерения; сценарии используют синхронно завершённый Task и ранее созданный DI scope. Результаты ориентировочные: стандартный процесс BDN не распознаёт .NET 11, а короткий запуск имеет широкие доверительные интервалы. Значения GC указаны в исходном отчёте BDN как число сборок на 1000 операций.

| Сценарий | Время | Память |
|---|---:|---:|
| Прямой вызов | 4–5 нс | 72 Б |
| Pipeline, 0 шагов | 45,8 нс | 272 Б |
| Pipeline, 1 шаг | 92,3 нс | 360 Б |
| Pipeline, 3 шага | 194,4 нс | 536 Б |
| Pipeline, 8 шагов | 415,4 нс | 976 Б |
| Досрочное завершение, перед 8 шагами | 90,7 нс | 328 Б |
| Регистрация, 0 / 1 / 3 / 8 шагов | 428 / 562 / 643 / 1008 нс | 2560 / 2984 / 3160 / 3936 Б |

Регистрация включает создание ServiceCollection, конфигурации и проверку pipeline, но не построение ServiceProvider. Прямой вызов возвращает Task.FromResult(42), поэтому выделяет 72 Б. Вызов pipeline использует уже созданный scope и шаги после первого разрешения. Досрочное завершение не разрешает оставшиеся восемь шагов. Источники и отчёты находятся рядом; повторный запуск требует --inProcess и --filter. Данные не показывают отдельно стоимость поиска, делегатов или DI; их вклад требует отдельных сравнительных экспериментов. Отдельные измерения генератора приведены в generator-report.md.
